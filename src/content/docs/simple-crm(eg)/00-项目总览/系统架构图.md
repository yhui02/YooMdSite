# 系统架构图

## 系统上下文

```mermaid
graph TD
  Sales[销售人员] -->|操作| App[Next.js 应用]
  Manager[销售经理] -->|操作| App
  Admin[管理员] -->|操作| App
  App -->|API Routes| API[后端 API]
  API -->|读写| DB[(SQLite)]
  API -->|AI 分析| AI[OpenAI API]
```

## 技术选型

| 层级 | 技术 | 原因 |
| --- | --- | --- |
| 全栈框架 | Next.js 14+ | 前后端一体化，部署简单 |
| 前端 UI | React + Tailwind | 轻量灵活，快速构建响应式界面 |
| 数据库 | SQLite | 零配置，单文件易备份 |
| AI | OpenAI API | 兼容 OpenAI 接口，性价比高 |
