# 快速开始

## 安装依赖

```bash
pnpm install
```

## 启动开发服务器

```bash
pnpm dev
```

访问 http://localhost:4321/

## 添加文档

1. 在 `content/docs/` 下创建项目目录
2. 添加 Markdown 文件到对应子目录
3. 刷新页面即可看到更新

## 配置文档路径

编辑 `src/config.ts`：

```typescript
export const docsConfig = {
  siteName: "YooMdSite",
  docsPaths: [
    {
      name: "我的项目",
      path: "./content/docs/my-project",
      description: "我的项目文档",
    },
  ],
  defaultDoc: "我的项目",
};
```

## 构建部署

```bash
pnpm build
```

构建结果输出到 `dist/` 目录。
