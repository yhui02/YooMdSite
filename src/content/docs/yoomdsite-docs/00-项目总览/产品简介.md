# YooMdSite 产品简介

## 产品名称
YooMdSite - Markdown 文档阅读平台

## 一句话描述
为技术团队提供美观、易用的 Markdown 文档在线浏览平台，支持多级目录导航、Mermaid 图表渲染和深色模式。

## 核心目标
1. 将本地 Markdown 文档快速发布为在线文档站点
2. 支持 Mermaid 流程图、ER 图、状态图等图表渲染
3. 提供多级目录导航，适合复杂项目文档
4. 支持深色模式，适配不同阅读场景

## 用户群体

| 角色 | 描述 | 核心诉求 |
| --- | --- | --- |
| 技术写作者 | 编写产品 PRD、技术文档 | 快速发布、多级目录、图表支持 |
| 开发团队 | 阅读系统设计文档 | 清晰的导航、代码高亮 |
| 产品经理 | 查看产品需求文档 | 美观的阅读体验、移动端适配 |

## 快速使用

### 第一步：添加文档
在 `content/docs/` 目录下创建你的项目文件夹，添加 Markdown 文档：

```
content/docs/你的项目名/
├── 00-项目总览/
│   ├── 产品简介.md
│   └── 系统架构图.md
├── 01-产品设计/
│   └── PRD.md
└── 99-附录/
    └── 更新日志.md
```

> 💡 使用数字前缀（如 `00-`、`01-`）控制目录和文档的显示顺序

### 第二步：配置路径
编辑 `src/config.ts`，添加你的文档路径：

```typescript
docsPaths: [
  {
    name: "我的项目",
    path: "./content/docs/我的项目名",
    description: "我的项目文档说明",
  },
],
defaultDoc: "我的项目",
```

### 第三步：查看效果
运行 `pnpm dev` 启动开发服务器，访问 http://localhost:4321/ 即可看到你的文档。
