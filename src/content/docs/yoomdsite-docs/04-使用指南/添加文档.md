# 使用指南

## 添加新文档项目

### 第一步：创建目录

```bash
mkdir -p content/docs/my-project/00-简介
```

### 第二步：添加 Markdown 文件

```markdown
# 产品简介

这是我的项目简介文档。

## 功能列表

- 功能一
- 功能二
- 功能三
```

### 第三步：更新配置

编辑 `src/config.ts`，添加新的文档路径：

```typescript
docsPaths: [
  {
    name: "我的项目",
    path: "./content/docs/my-project",
    description: "我的项目文档",
  },
  // 更多项目...
],
```
