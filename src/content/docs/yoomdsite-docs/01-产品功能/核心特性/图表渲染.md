# 图表渲染能力详解

YooMdSite 内置 Mermaid.js，支持多种图表类型的自动渲染。

## 支持的图表类型

### 1. 流程图 (Flowchart)

用于展示系统流程、决策树等。

```mermaid
flowchart TD
  Start([开始]) --> Input[输入数据]
  Input --> Validate{验证通过?}
  Validate -->|是| Process[处理数据]
  Validate -->|否| Error[返回错误]
  Process --> Output[输出结果]
  Output --> End([结束])
  Error --> End
```

### 2. ER 图 (Entity Relationship)

用于展示数据库表关系。

```mermaid
erDiagram
  PROJECT ||--o{ DOC : contains
  PROJECT {
    string id PK
    string name
    string description
  }
  DOC {
    string id PK
    string title
    string path
    string content
  }
  DOC ||--o{ SECTION : has
  SECTION {
    int id PK
    string heading
    int level
  }
```

### 3. 状态图 (State Diagram)

用于展示状态流转。

```mermaid
stateDiagram-v2
  [*] --> 草稿
  草稿 --> 待审核 : 提交
  待审核 --> 已发布 : 审核通过
  待审核 --> 草稿 : 审核驳回
  已发布 --> 已归档 : 归档
  已归档 --> [*]
```

### 4. 时序图 (Sequence Diagram)

用于展示系统交互时序。

```mermaid
sequenceDiagram
  participant Browser as 浏览器
  participant Astro as Astro 构建
  participant Markdown as markdown-it
  participant Mermaid as Mermaid
  Browser->>Astro: 请求页面
  Astro->>Markdown: 解析 MD 文件
  Markdown-->>Astro: 返回 HTML
  Astro->>Mermaid: 渲染图表
  Mermaid-->>Astro: 返回 SVG
  Astro-->>Browser: 返回完整页面
```

### 5. 甘特图 (Gantt)

用于展示项目时间线。

```mermaid
gantt
  title YooMdSite 开发计划
  dateFormat  YYYY-MM-DD
  section 基础框架
  项目搭建        :done,    des1, 2026-05-01, 7d
  Markdown 解析   :done,    des2, after des1, 5d
  section 功能增强
  Mermaid 支持    :active,  des3, after des2, 5d
  深色模式        :         des4, after des3, 3d
  section 部署
  GitHub Pages    :         des5, after des4, 3d
```

## 渲染原理

1. Markdown 内容中的 ```mermaid 代码块被提取
2. Mermaid.js 在客户端将代码块转换为 SVG 图表
3. 自动添加缩放、悬停放大等交互功能
4. 深色模式下自动反转图表颜色
