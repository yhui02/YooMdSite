# 代码高亮

YooMdSite 使用 Highlight.js 实现代码语法高亮，支持多种编程语言。

## 支持的语言

| 语言 | 示例 |
| --- | --- |
| JavaScript/TypeScript | 前端代码 |
| Python | 脚本和后端 |
| SQL | 数据库查询 |
| Markdown | 文档语法 |
| Bash | Shell 命令 |
| YAML | 配置文件 |

## JavaScript/TypeScript 示例

```typescript
interface DocsConfig {
  siteName: string;
  docsPaths: DocPath[];
  defaultDoc: string;
}

interface DocPath {
  name: string;
  path: string;
  description: string;
}

export const docsConfig: DocsConfig = {
  siteName: "YooMdSite",
  docsPaths: [
    {
      name: "Simple CRM",
      path: "./content/docs/simple-crm-demo",
      description: "简单CRM系统设计文档（示例）",
    },
  ],
  defaultDoc: "Simple CRM",
};
```

## Python 示例

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/api/docs")
async def get_docs(project: str):
    """获取项目文档"""
    docs = load_docs_from_dir(f"./content/docs/{project}")
    return {
        "project": project,
        "doc_count": len(docs),
        "docs": docs
    }
```

## SQL 示例

```sql
CREATE TABLE projects (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE documents (
    id INTEGER PRIMARY KEY,
    project_id INTEGER REFERENCES projects(id),
    title TEXT NOT NULL,
    path TEXT NOT NULL,
    content TEXT,
    UNIQUE(project_id, path)
);
```

## Bash 示例

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建静态站点
pnpm build

# 预览构建结果
pnpm preview
```

## YAML 示例

```yaml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pnpm install
      - run: pnpm build
```
