# 多级目录导航

YooMdSite 支持多级目录结构，适合复杂项目文档的组织。

## 目录层级示例

```
content/docs/项目名/
├── 00-项目总览/              # 一级目录
│   ├── 产品简介.md           # 二级文档
│   └── 系统架构图.md
├── 01-产品功能/              # 一级目录
│   ├── 功能特性.md           # 二级文档
│   └── 核心特性/             # 二级目录
│       ├── 图表渲染.md       # 三级文档
│       └── 代码高亮.md
└── 99-附录/
    └── 更新日志.md
```

## 侧边栏展示效果

侧边栏会根据目录结构自动生成，支持：

- **一级目录**：加粗显示，作为分组标题
- **二级目录**：缩进显示，作为子分组
- **文档文件**：可点击的链接，点击跳转查看

## 编号前缀的作用

使用 `00-`、`01-`、`99-` 等数字前缀可以控制目录和文档的显示顺序，确保文档按照你期望的顺序排列。

## 实际效果

查看本文档系列的左侧导航栏，即可看到多级目录的实际效果：

- `00-项目总览` 下有直接文档
- `01-产品功能` 下有文档和子目录
- `02-技术架构` 下有多个子目录
