# 前端架构

## 组件结构

```mermaid
graph TD
  subgraph 页面
    Index[首页 index.astro] --> Layout[DocLayout.astro]
    Doc["文档页 [...path].astro"] --> Layout
    NotFound[404页 404.astro] --> Layout
  end
  subgraph 布局
    Layout --> Header[顶部导航栏]
    Layout --> Sidebar[侧边栏]
    Layout --> Main[内容区]
    Layout --> Footer[底部信息栏]
  end
  subgraph 侧边栏
    Sidebar --> TreeNav[文档树导航]
    Sidebar --> ArticleNav[文章目录]
  end
```

## 技术栈

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Astro | 4.x | 静态站点生成框架 |
| Tailwind CSS | 3.x | 原子化 CSS 框架 |
| markdown-it | 14.x | Markdown 解析 |
| Mermaid | 10.x | 图表渲染 |
| Highlight.js | 11.x | 代码语法高亮 |

## 页面路由

| 路由 | 文件 | 说明 |
| --- | --- | --- |
| `/` | `index.astro` | 首页，显示文档卡片 |
| `/docs/[...path]` | `[...path].astro` | 文档内容页 |
| `/404` | `404.astro` | 404 错误页 |

## 主题切换原理

```mermaid
stateDiagram-v2
  [*] --> 加载页面
  加载页面 --> 检查localStorage
  检查localStorage --> 使用深色 : 已保存dark
  检查localStorage --> 使用浅色 : 已保存light
  检查localStorage --> 跟随系统 : 未保存
  跟随系统 --> 监听系统变化
  监听系统变化 --> 使用深色 : 系统变暗
  监听系统变化 --> 使用浅色 : 系统变亮
  使用深色 --> 手动切换 : 用户点击
  使用浅色 --> 手动切换 : 用户点击
  手动切换 --> 保存偏好
  保存偏好 --> [*]
```
